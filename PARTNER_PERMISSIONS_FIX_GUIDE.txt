=====================================================

This causes 404 if:
1. Online Course addon is not installed
2. The addon is installed but not activated
3. Routes are not configured

FIX OPTIONS:

Option A: Install Online Course Addon
--------------------------------------
The addon exists on your server:
- addons/online_course/
- It's currently inactive

Activate it in: Admin → Modules → Online Course

Option B: Use Custom Courses Page
----------------------------------
If addon stays disabled, it will show:

The controller already handles this automatically!
